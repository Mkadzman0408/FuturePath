# Setup Supabase with Next.js SSR Client

In this guide, we are going to learn how to do a supabase integration. If you want to connect a database to your Next.js application, then doing a supabase integration is a great choice. Using the new `@supabase/ssr` package makes it super easy to set up your supabase integration on server-rendered pages, API routes, and middleware.

Let's look at how to get started.

## Install the dependencies

First, we will run the install command:

```bash
npm install @supabase/supabase-js @supabase/ssr
```
